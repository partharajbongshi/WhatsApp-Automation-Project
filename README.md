# 📱 WhatsApp Automation & AI Integration Practice

This is a practical project focused on setting up an automated system to send customized messages on WhatsApp using Google Sheets and cloud automation tools.

## 🛠️ What I Did in This Project:
- **Google Sheets Database:** Created and structured a contact database including names, phone numbers, and custom message parameters.
- **Cloud Automation Logic:** Practiced setting up automation workflows on Make.com using Green-API and Z-API modules to bridge contact data with WhatsApp servers.
- **Alternative Free Solution:** Tested a cost-free solution using the official Google Sheets extension (Walution) combined with WhatsApp Web to successfully bypass third-party API trial limits.
- **Results:** Successfully verified the automation setup by triggering automated, personalized message deliveries to the destination numbers.
